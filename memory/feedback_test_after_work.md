작업 후 테스트 코드를 만들고 실행까지 해서 결과를 확인한다.

**Why:** 사용자가 명시 요청 (2026-04-13). 배포만 하고 동작 검증 없이 끝내는 패턴을 지양.

**How to apply:**
- 새 기능/변경마다 해당 로직에 대한 단위 테스트 또는 스모크 테스트 작성
- 테스트 프레임워크: 프로젝트에 맞게 (Python → pytest, PHP → PHPUnit 등)
- 테스트 실행 결과를 보고한 뒤 작업 완료로 처리
- 배포 후에는 엔드포인트 스모크 테스트 (curl/httpie)로 실제 동작 확인
- **테스트 코드는 커밋·푸시 금지** (프로젝트 컨벤션, 2026-04-29 명시 지적). 작성·실행·결과 보고까지만. 파일은 `/tmp/` 또는 untracked 위치에 두고 `git add` 하지 않는다. 이미 커밋했다면 `git reset` 으로 즉시 제거.
