# 블로그 최신 어투 요약 (2026-11-12 정리)

이 파일은 `~/Desktop/blog/02-본문.md` §1~§9 와 메모리, 원고 md 의 「사용자 에디터 수정」 기록을 한곳에 모은 것이다.
**다른 세션·에이전트는 이 파일만 읽고 블로그 본문을 쓸 수 있어야 한다.** `02-본문.md` 와 부딪치면 이 파일이 이긴다.
새 사용자 수정이 나오면 **이 파일의 표에 한 줄 추가**한다 (원고 md 에만 남기지 않는다).

## 1. 우선순위

1. 사용자가 이번 글에서 직접 한 말·에디터 수정 (되돌리지 않고 원고 md 에 반영)
2. 이 파일
3. 기본 문체 정본 `posts/45.우메다 만두 신짱 육즙만두 후기.md` (`02-본문.md` §1 ★★★)
4. 이모지·`~용` 참고 글 `blog.naver.com/jiyipartyplanner/224454583879` (2026-11-06, 65편)
5. `~/Desktop/blog/02-본문.md` §1~§9 의 나머지

## 2. 뼈대 (결혼식 업체 후기 A 유형, 66~70편)

- `안녕하세요!` → `오늘은 ... ==핵심 한 구== ... 후기예요 😊` → 앞 글 언급 한 줄 → 하이픈 정보 블록 3줄 (`- 업체 :` `- 위치 :` `- 이번 글 :`)
- 소제목은 **명사 한 단어 4개 안팎**, 인용구4(quotation_underline) 안에 **굵게**. 「마무리」가 마지막
- 끝은 `읽어주셔서 감사합니다.` 한 줄. 정리 문장·불릿 요약을 쓰지 않는다
- 사진은 그 장면을 말한 문장 바로 뒤. 얼굴은 모자이크

## 3. 어미와 말투 신호

| 항목 | 규칙 | 실제 예 |
|---|---|---|
| 기본 어미 | `~에요` `~어요` `~예요`. `~습니다` `~이다` 금지 (IT 뉴스만 예외) | |
| 회상 어미 | `~더라구요` (`~더라고요` 아님) | 「제일 맛있더라구요 !」 「아이보리색은 좀 별로더라구요」 |
| `~용` 어미 | 글 전체 **5줄 이하**. 넘기면 「너무 용용 거리는데」 | 「그려지더라구용」 |
| `!` `?` | 사용자는 **앞에 한 칸 띄운다** | 「넘어갔어요 !」 「풍성이랄까요 ?」 「잘 어울릴 수도 있어요 !」 |
| 말줄임 | `..` 두 점, 문장 중간에도 | 「프라이샷은 이쁘지만 ..」 「신부님 ..!!」 |
| 웃음·울음 | `ㅋㅋ` `ㅠㅠ` 를 문장 끝에, 띄우거나 붙이거나 | 「신고갈뻔 했어요ㅋㅋ」 「추천해주신건 아닌 거 같아요 ㅋㅋ」 |
| 늘여 쓰기 | 강조 단어를 늘인다, 끝을 늘인다 | 「훠얼씬」 「매우매우」 「리뷰해보겠습니다앙」 |
| 괄호 한 줄 | 결론을 괄호로 짧게 | 「(이 드레스는 고르지 않았어요.)」 |
| 맞춤법 | 사용자가 쓴 구어 표기(`생겻어요` `이쁘다` `아니여서`)는 **고치지 않는다** | 「우유 흘린 것 같이 생겻어요」 |
| 마침표 | 사용자가 쓴 줄은 마침표 없이 끝나는 경우가 많다. 그대로 둔다 | 「가슴선은 참 이쁘게 만든 것 같아요」 |

## 5. 내용 — 사용자가 고친 방향

| 사용자가 한 일 | 예 (편) |
|---|---|
| **사람을 넣는다** - 직원·실장님·사장님의 말과 행동 | 「매니저님이 신부님 ..!! 하고 다급하게 신발들고 오시더라구요」(66) 「실장님이 괜히 추천해주신건 아닌 거 같아요 ㅋㅋ」(70) |
| **자기 몸·조건과 연결한다** | 「제가 어깨가 좁은 편인데 홀터넥을 덧대니까 ...」(69) 「요구했던 조건은 ... 매우매우 풍성하고 꽉차는 느낌」(70) |
| **비유 한마디** | 「우유 흘린 것 같이 생겻어요」(69) |
| **장점 하나 인정 + 솔직하게 깎기** | 「가슴선은 참 이쁘게 만든 것 같아요」 → 「근데 좀 정돈되지않은 풍성이랄까요 ?」(70) |
| **비교로 끝낸다** | 「유색 캉캉은 이쁜데 아이보리색은 좀 별로더라구요」(70) |
| **사진 설명을 장면 이야기로 바꾼다** | 「바닥에 앉으면 치마가 동그랗게 펼쳐져요」 삭제 → 「프라이샷도 찍어봤어요 !」(70) |
| **딱딱한 도입을 지운다** | 「결론부터 말하면」 삭제(64, 70) |
| **작은 웃음 에피소드를 붙인다** | 「너무 편해서 집갈때 신고갈뻔 했어요ㅋㅋ」(66) |

## 6. 쓰지 않는다 (반려된 것)

- 사용자가 말하지 않은 감상·이유·권유. 초안에서 사진만 보고 쓴 「꽃 한 송이 같았어요」류는 지운다. **모자라면 묻는다**
- 사진 속 사물을 늘어놓는 설명문. 사용자는 그 자리를 경험·사람 이야기로 바꾼다
- 분량 채우기용 문장, 키워드 억지 삽입, 소제목 잘게 쪼개기 (`02-본문.md` §1 ★★ 38편)
- 마무리 정리·불릿 요약 (36~38편 연속 삭제)
